Ebike

Vehicle Control Unit

Project Description

Vehicle Control Unit is the main controller of an electric bike system. It control operation of vehicle, manage battery, control motor inverter, tracking device via GNSS and notify to user via mobile app with cellular.

Key Feature

  • Centralized control of vehicle operation and system states
  • Control and monitor the Motor Inverter, Battery Management System
  • Monitor vehicle conditions and handle system faults.
  • Tracking device via GNSS and Cellular
  • Display vehicle information and status on an RGB LCD
  • Role Technical Lead
  • Period November 2025 – April 2026
  • Team size 3

My Responsibilities

  • Requirement analysis
  • Design Software architecture using UML
  • Create and implement unit, integration (Using Ceedling + Ram Montior application) and sytem test to validate machine behavior against functional specifications
  • Implemented communication interfaces: I2C, UART, CAN between the VCU and other components like RFID, IoExp, IMU, GNSS, Cellular, Battery Control, and Motor Inverter
  • Develop RFID stack base on NCI standard for communicate with RFID device via multiple protocol like I2C, SPI.
  • Developed a CAN communication stack for managing the Motor Inverter and Battery Manager, with mechanisms to prevent data loss and missed messages.
  • Designed a non-blocking, event-driven I2C communication architecture for multiple tasks using sharing resource, preventing race-condition, deadlocks, priority inversion, and timing requirement.
  • Designed a UART communication mechanism using a ring buffer to reliably handle GNSS and Cellular data and prevent data loss.
  • Implemented mechanisms to protect and synchronize shared data between tasks
  • Design and develop update firmware via CAN protocol follow UDS standard
  • Designed and developed an LVGL-based UI for an RGB LCD display, using SquareLine Studio for UI design and implementation.
  • Developed vehicle features including RFID authentication, lighting system, horn, turn signals, buzzer, and other vehicle I/O functions.
  • Developed telematics features using Cellular/GNSS module for remote monitoring, remote control, and GNSS tracking.
  • Used CANoe to create CAN databases, analyze bus load, and simulate network nodes to validate system behavior before hardware integration.
  • Designed and developed the application layer to manage overall vehicle states and control vehicle operation.
  • Leveraged AI tools to develop automation solutions and tools, significantly reducing task completion time and enhancing overall team productivity
