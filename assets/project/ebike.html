Ebike

Vehicle Control Unit

Project Description

Vehicle Control Unit is the main controller of an electric bike system. It control operation of vehicle, manage battery, control motor inverter, tracking device via GNSS and notify to user via mobile app with cellular.

My Responsibilities

  • Requirement analysis
  • Software architecture design
  • Create and implement unit, integration, comprehensive, and system tests
  • Develop low-level layers: I2C, UART, CAN, NVS
  • Develop feature: NFC controller, Battery communicate, Motor inverter control, peripheral system, user interface, tracking GNSS and vehicle operations.
  • Design mechanisms to protect and synchronize data between tasks
  • Design and develop update firmware

Technologies

  • MCU: ESP32
  • RTOS: FreeRTOS
  • Language: C / Python
  • Unit-Test: Ceedling
